伸缩伞 Blockbench 模板说明（修正版）
====================================

上一版的问题：
- `.bbmodel` 用了 format_version 5.0 + 额外的 groups 数组，部分 Blockbench 版本
  会打开成空动画列表；
- 打开后默认在“编辑”模式，看不到动画时间轴，看起来就像“没有动画”；
- 只有一个静止姿势，所以看不到“收缩/打开”两个状态。

这一版已修正：
- 工程格式改为 Blockbench 4.10（4.x / 5.x 都能打开）；
- 去掉了 groups 数组，改用 outliner（和 Blockbench 自己保存的工程一致）；
- 包含 open / close 两段动画：open 的 0.0s = 收缩，0.4s = 打开；
- 已在 Blockbench 里实际打开验证：动画列表能读到 open / close，
  每个动画有 13 个骨骼的位移/旋转/缩放关键帧。

   Blockbench 工程（模型 + 贴图 + open/close 动画），推荐 Blockbench 4.10 以上。

2. telescopic_umbrella.png
   128x64 贴图（已内嵌，单独一份方便重绘）。
   UV 区域：
   - (0,0)-(63,63)     伞面布料
   - (64,0)-(79,15)    不锈钢伞杆
   - (80,0)-(95,15)    深灰塑料握把
   - (96,0)-(111,15)   浅灰伞顶/伞帽
   - (112,0)-(127,15)  深色伞骨
   - (64,16)-(79,31)   木头（备用）
   - (80,16)-(95,31)   红色（备用）
   - (96,16)-(111,31)  浅蓝（备用）
   - (112,16)-(127,31) 深色握把（备用）

3. telescopic_umbrella.animation.json
   Bedrock 动画 JSON（备用/参考）；正式编辑以 .bbmodel 里的动画为准。

4. closed.png / open.png / animation.gif
   离线渲染的收缩状态、打开状态和开合动画预览。

骨架
----
umbrella（根骨骼，握把底部 y=0）
├─ handle       塑料握把 + 腕带
├─ shaft        三段伸缩伞杆（Y 缩放 0.45 ↔ 1）
├─ runner       滑套（上下滑动）
└─ canopy       伞面总骨骼（hub 在 y=21.44）
   ├─ hub / finial
   └─ rib_0 ... rib_9
      ├─ panel_i      伞面布片
      └─ ribstick_i   伞骨

动画
----
open（0.0s → 0.4s）：
- shaft Y 缩放 0.45 → 1（伞杆伸出）
- canopy 位置 y -11.52 → 0
- canopy 缩放 (0.08, 1.0, 0.08) → (1, 1, 1)
  （X/Z 收缩成细长的一束，Y 保留长度，看起来像收拢的伞布）
- runner 位置 y -9.9 → 0
- rib_0..9 的 Z 旋转 -65° → 0°

close（0.0s → 0.4s）：正好反过来。

在 Blockbench 里看收缩/打开
----------------------------
1. 用 Blockbench 4.10 以上打开 telescopic_umbrella.bbmodel；
2. 看窗口**右上角**，有“编辑模式 / 绘画模式 / 动画模式”三个按钮，
   点 **动画模式**（Animate）。默认打开时通常停在“编辑模式”，
   所以看不到动画时间轴，这不是没有动画；
3. 窗口底部会出现时间轴，左侧/左下是动画列表，选 **open**；
4. 把时间轴拖到 **0.0s**：收缩状态；
   拖到 **0.4s**：打开状态；点播放可看整个过程；
5. 选 **close** 可以看反向收起。

如果点“动画模式”后动画列表还是空的：
- 确认打开的是 `telescopic_umbrella.bbmodel`，不是 `.animation.json`；
- 确认 Blockbench 版本 ≥ 4.10（推荐 5.x）；
- 把 Blockbench 的版本号和“动画模式”下的截图发我，我再查。
